## LinkedIn — project description

Completed an end-to-end e-commerce analytics portfolio project using the Olist Brazilian E-Commerce Public Dataset. I used SQL and Python/Pandas to validate data, analyse sales and product categories, examine payment patterns, measure delivery performance, and compare delivery timeliness with customer review scores. I also created an interactive Plotly dashboard and documented the KPI definitions, analytical limitations, and business recommendations.

The analysis covered 99,441 orders. Among 96,470 delivered orders eligible for delivery-performance analysis, 8.11% arrived later than estimated. The late-delivery rate increased across the observed years, from 1.50% in 2016 to 9.37% in 2018. Late orders also had lower average review scores than on-time/early orders; this is a descriptive association rather than proof of causality.

Project repository: https://github.com/Zaheermuhammadasad/olist-ecommerce-analytics
