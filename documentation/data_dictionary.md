# Data Dictionary

This document describes the Olist dataset tables, columns, relationships and analytical purpose.

## Source Tables

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation
- Product Category Translation

## Purpose

The data dictionary will be completed during the data-understanding and data-quality stages of the project.

It will document:

- Column definitions
- Data types
- Primary and foreign keys
- Table relationships
- Missing values
- Duplicate records
- Analytical use of each field
